# Chist — многолетний электронный журнал

Laravel 9 + Blade + Bootstrap 5 + jQuery + SQLite.

Система рассчитана на годы: **учебный год → полугодие → состав группы → занятия → посещаемость/оценки → семестровые результаты**. Старые периоды сохраняются и доступны в архиве.

## Роли
Super Admin, Admin, классный руководитель, преподаватель, староста. Права хранятся отдельно от ролей, поэтому можно добавлять собственные роли.

## Первый запуск
После установки зависимостей и настройки SQLite:
```bash
php artisan migrate --seed
php artisan chist:superadmin
```
Команда интерактивно запросит имя, e-mail и пароль. Пароль не хранится в репозитории.

## Безопасность
Обычный Admin не может назначать/редактировать Super Admin. Super Admin имеет полный доступ. Для остальных ролей действия определяются permissions; область данных (своя группа/свои занятия) дополнительно ограничивается Policies.

## История
Студент имеет постоянный ID, а переходы между группами фиксируются отдельно. Повторный импорт расписания не удаляет посещаемость, оценки или семестровые результаты.
