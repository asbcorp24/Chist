# Chist — многолетний электронный журнал

Laravel 9 + Blade + Bootstrap 5 + jQuery + SQLite.

Система проектируется не под один семестр, а на годы: **учебный год → полугодие → состав группы → занятия → посещаемость/оценки → семестровые результаты**.

## Главное
- прошлые периоды не перезаписываются и доступны в архиве;
- закрытый период блокируется от обычного редактирования;
- студент сохраняет постоянный ID при переводе между группами;
- история групп хранится в student_group_memberships;
- повторный импорт расписания не должен удалять журнал;
- роли: администратор, классный руководитель, преподаватель, староста;
- все изменения журнала в дальнейшем журналируются в audit_logs.

## Первый этап
В миграциях уже заложены учебные годы/периоды, группы, студенты и история состава, преподаватели, предметы, расписание, фактические занятия, посещаемость, оценки, семестровые результаты, импорт и аудит.

Работа ведётся в feature/electronic-journal-foundation и будет предложена через PR перед слиянием в main.
