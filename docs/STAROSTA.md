# Роль «Староста»

Староста — системная роль уровня 20.

Разрешено:
- видеть расписание;
- видеть список студентов своей группы;
- видеть посещаемость своей группы;
- отмечать посещаемость своей группы.

Запрещено:
- выставлять и изменять оценки;
- выставлять семестровые результаты;
- редактировать студентов;
- менять расписание;
- видеть данные других групп.

Фактическое ограничение «только своя группа» должно выполняться серверной Policy. Пользователь-староста связывается с карточкой студента через users.student_id, поэтому группа определяется из student.current_group_id и исторического student_group_memberships.
