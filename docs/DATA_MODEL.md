# Модель многолетнего журнала

## Периоды
Учебный год и полугодие — отдельные сущности. Никакая оценка или посещаемость не определяется понятием «текущий год» без ссылки на конкретный период.

Закрытие периода переводит его в архивный режим. Архив остаётся доступен для просмотра и отчётности.

## Студент
Студент имеет постоянный ID. Поле current_group_id нужно для быстрого текущего интерфейса, а историческая принадлежность хранится в student_group_memberships. Перевод, академический отпуск, отчисление и выпуск не удаляют историю.

## Расписание и журнал
schedule_entries — импортируемый план. lesson_occurrences — фактически состоявшиеся/запланированные занятия. attendance_records и grade_records ссылаются на lesson_occurrences, поэтому повторный импорт расписания не уничтожает историю.

## Семестровые результаты
semester_results привязаны к academic_period_id + student_id + subject_id. После закрытия периода результат блокируется locked_at.

## Права
admin — всё.
curator — состав своей группы, просмотр журнала и отчёты.
teacher — посещаемость и оценки только своих занятий/предметов.
starosta — посещаемость своей группы без права выставлять оценки.

Проверки прав должны выполняться серверными Policy/Gate, а не только скрытием кнопок.
