# Импорт Rector-College XML

Исходный XML читается как Windows-1251 и преобразуется в UTF-8. Импорт выполняется транзакционно.

Импортируются:
- даты учебного периода;
- времена пар;
- специальности;
- группы;
- аудитории;
- преподаватели;
- предметы;
- виды занятий;
- нагрузки и расписание;
- class_id преподавателя используется для назначения классного руководителя.

Повторный импорт того же полугодия деактивирует предыдущую версию schedule_entries и создаёт/обновляет актуальные записи. attendance_records, grade_records, lesson_occurrences и semester_results не удаляются.

Следующий этап импортера: replacements и holidays, затем генерация lesson_occurrences по календарным датам.
